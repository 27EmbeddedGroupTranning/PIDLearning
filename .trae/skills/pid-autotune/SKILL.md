# PID 自动整定：阶跃辨识 + 继电自整定 + Z-N + 闭环验证

为任意对象（给定 G(s)、仿真代码或实测数据）整定 PID 并给出一组经闭环验证的基准参数。
默认**只读用户代码、不改结构**：参数以代码行形式交给用户自行粘贴，除非用户明确要求代改。
完整整定表、拟合公式与分类决策树见 [references/zn-tables.md](references/zn-tables.md)；
可执行脚本见 [scripts/autotune.py](scripts/autotune.py)（纯标准库，Python 3.9+）。

## 0. 收集输入（缺什么问什么，一次问完）

- 对象来源三选一：用户直接给 G(s)；用户的仿真代码（读动力学方程、dt、限幅、单位）；实测阶跃数据。
- 控制器事实：dt、输出限幅、微分是否带低通及其时间常数、抗饱和方式、PID 形式（理想并联 Kp/Ki/Kd 或串联）。
  **必须读用户的 PID 实现并在验证时原样复现**；读不到才用脚本内置参考 PID，并向用户声明。
- 单位（rad/deg、N·m 等）与真实工况（典型阶跃幅度、最大负载扰动、噪声水平）。

## 1. 搭建对象与脚本

- G(s) 已知 → 直接 `--num/--den`（系数降幂）。
- 仿真代码对象 → 按脚本头部契约写临时 plant 模块，放**系统临时目录**（勿写入用户工作区），
  积分顺序与用户仿真逐行一致（先速度后角度这类顺序差异会改变结论）。
- 硬件已测得 Ku/Tu → `--ku --tu` 跳过仿真直接查表。
- 执行器正方向与被控量正方向相反时加 `--invert`。

## 2. 分类（`--mode step`）

- 输出收敛 → 自平衡对象，FOPDT 两点拟合 K/L/T；仅当 L/T 明显（>0.3）才可用开环 Z-N 表。
- 输出不收敛（斜坡/抛物线）→ 积分类对象 → 开环 Z-N 退化（L≈0），必须走继电法。
- 含积分器的对象纯 P 永远到不了 −180° 相位、不会临界振荡 → **禁止建议"加大 Kp 找振荡"**。

## 3. 继电测试（`--mode relay` 或 all）

- h 取限幅的 20–40%，且必须大于最大负载扰动；eps：无噪声取输出量程的 1e-3~1e-2，有噪声取 >3 倍噪声幅值。
- 脚本自动以 0.6h / 1h / 1.2h 复测三档：Ku、Tu 取中档，报告离散度（非正弦波形的正常描述函数偏差）。
- 出现 "Tu 逼近采样周期" 警告说明对象无明显死区 → 改用开环 Z-N 或增大 eps。

## 4. 查表与闭环验证（`--mode tables` 或 all）

- 选表：死区主导 → 经典 Z-N 可用；积分/惯性主导 → Tyreus-Luyben 优先，经典表仅作对照（其 Ki 偏强易振荡）。
- 验证场景必须等于用户真实工况（阶跃幅度、负载、时长、控制器结构、dt、抗饱和）。
- 指标：超调、2% 调节时间、负载跌落、恢复时间、IAE、峰值|u|；发散直接淘汰。
- 用 `--current` 加入用户现有参数作对照，量化改进幅度。

## 5. 交付规则

- 挑选顺序：稳定 → 超调满足用户容差 → IAE 最小；同时给保守备选（Kp、Ki 减半）。
- 峰值|u| 触顶必须说明；真机需提醒齿隙、电流环延迟未建模——出现嗡鸣/抖动先减半 Kp、Ki。
- 参数给 3 位有效数字；用户有参数文件（如 tuning.cpp）→ 给出现成代码行让用户自己粘贴。
- 报告必须附每步实测数据（辨识的 K/L/T 或 K_i/τ、A、Tu、Ku 及多档 h 离散度），不要只给结论。

## 6. 复查

- 换更大负载、更小阶跃复跑确认鲁棒；确认大阶跃饱和段抗饱和有效。
- 临时 plant 模块与运行产物留在临时目录，告知用户位置便于复跑，不留在工作区。

## 已踩过的坑（必须遵守）

- 继电切换必须按"状态翻转"事件记录；按电平逐拍记录会把 Tu 测成 2 个采样周期（实际踩过）。
- 描述函数 Ku 随 h 变化（A 大致 ∝ h^0.25），必须多档 h 复测取中值。
- 验证时控制器结构、微分滤波、抗饱和、dt、积分顺序任何一处与用户实现不符，结论即无效。
- 单位混乱（rad/deg）是最常见翻车点，写 plant 模块前先固定单位并写注释。
